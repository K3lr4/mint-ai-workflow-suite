# mint-ai-workflow-suite 1.0.0

This release contains three small Linux desktop tools for screen, audio, and
image workflows. It is a useful little toolbox, assembled with enthusiasm,
code, and a statistically significant amount of AI assistance:

- Audio Clipping Tool records system audio and places the resulting clip on
  the clipboard.
- Video Clipper records the visible X11 desktop together with the computer's
  output audio and places the resulting MP4 on the clipboard.
- Screenshot Marker annotates screenshots with ellipses, arrows, numbers,
  movement, rotation, and cropping tools.

The release includes source code, Flatpak manifests, x86_64 application
bundles, installation material, screenshots, checksums, and third-party
license notices. See `THIRD-PARTY-NOTICES.md` and `LICENSE-STATUS.md` before
redistributing any part of the bundle.
