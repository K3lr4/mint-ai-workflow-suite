# mint-ai-workflow-suite 1.0.0

Three small Linux Mint/X11 desktop tools for practical AI workflows:

- **Audio Clipping Tool** records system audio and puts the resulting clip on
  the clipboard.
- **Video Clipper** records the visible desktop together with computer output
  audio and puts the resulting H.264/AAC MP4 on the clipboard.
- **Screenshot Marker** annotates clipboard screenshots with ellipses, arrows,
  numbers, movement, rotation, and cropping.

This repository is the deliberately isolated public release home. The
complete source tree, Flatpak manifests, tests, installer, screenshots,
checksums, and third-party license texts are delivered in the release archive
attached to version `1.0.0`. The release page also contains the three local
x86_64 Flatpak application bundles.

## Download

Open the [1.0.0 release](../../releases/tag/v1.0.0) and download the asset
that matches your purpose:

- `mint-ai-workflow-suite-1.0.0.tar.gz` — complete source and release bundle.
- `Audio-Clipping.flatpak` — audio recorder.
- `Video-Clipper.flatpak` — desktop video recorder with system-output audio.
- `Screenshot-Markierer.flatpak` — screenshot annotation tool.

The archive includes `THIRD-PARTY-NOTICES.md`, the complete license texts in
`licenses/`, the SPDX/AppStream metadata, and the exact SHA-256 checksums.
The Flatpaks target the GNOME 50 runtime and are x86_64 build artifacts.
